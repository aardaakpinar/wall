# Why Choose Wall?

Creating a portfolio should feel simple, fast, and enjoyable.  
Wall was built to remove unnecessary complexity and let you focus on your content instead of configuration headaches.

## YAML-First Configuration

Everything in Wall is driven by a single YAML file.

That means you can:

- edit content quickly
- reorder sections easily
- keep your portfolio clean and maintainable
- avoid large frontend frameworks

A portfolio should not require hundreds of files just to update a link or add a project.

## Built for Bento Grids

Wall is designed around modern Bento Grid layouts.

This allows you to mix:

- hero sections
- project cards
- links
- blog posts
- images
- social profiles

inside a responsive and visually balanced layout.

## Static and Fast

Wall generates static pages, making it extremely lightweight and fast.

Benefits include:

- instant loading times
- simple deployment
- GitHub Pages support
- no backend required

## Easy to Extend

Wall keeps the core small while remaining flexible.

You can easily add:

- custom cards
- themes
- markdown blogs
- animations
- external integrations

without rewriting the entire system.

## Final Thoughts

Wall is focused on simplicity, customization, and speed.

If you want a modern portfolio system that stays easy to maintain as your projects grow, Wall provides a clean foundation to build on.
